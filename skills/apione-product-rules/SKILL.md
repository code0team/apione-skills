# apione-product-rules

先读 [业务规则](references/rules.md)，按问题引用相关决策时间。回答时区分“业务已确认”和“线上已验证”；本技能来自聊天记录，不证明当前部署状态。

- 网页通道、API Key 档位、工作区是不同维度，不能混为一个分组。
- 使用最新明确确认的规则；旧方案只用于解释变更。
- 涉及实际价格、奖励到账或权限变更，先核对当前后台；本技能不授权改账或派发奖励。
- 信息未确认时说明缺口，不根据旧截图或产品常识补全。

输出问题结论、适用范围、决策日期，以及需要核对的上线状态。
