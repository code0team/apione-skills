# apione-provider-routing

读 [渠道与路由操作](references/routing.md)。先确认目标入口（Web 或 API）、分组、模型、协议和请求能力，再提出配置或测试方案。

将“模型出现在列表”“真实请求成功”“支持工具/思考/视觉”分别验证。上游是 OpenAI 兼容接口，不代表支持所有兼容模型。

对每次评估输出：提供商别名、分组、模型、协议、所需能力、测试时间、次数、成功率、首字延迟、总耗时、错误分类和建议。没有明确算法时不要编造综合分数。

真实调用可能消耗额度，只有任务授权测试时才执行；仓库不保存调用凭据。删除渠道、改线上路由和付款不是知识查询的附带动作。
