# apione-incident-triage

按 [排障与验收](references/triage.md) 建立证据链。先拿到入口、账户/工作区、分组、模型、请求时间、平台请求 ID、任务 ID、上游请求 ID 和错误；缺哪个就明确缺口。公开输出使用匿名标识。

区分浏览器展示、代理层、网关路由、上游处理、任务持久化、账本结算，不根据某一端成功或失败就替整条链下结论。

输出现象、已验证证据、待验证假设、下一步及负责角色。修复说明、部署完成、复测通过分别记录；不要把“已提交 main”当作线上已修复。
