# apione-client-integration

读 [客户端接入与边界](references/integration.md)。收集系统、客户端版本及安装包日期、目标工具版本、模型、协议、Key 分组、是否旧会话和最近一次错误。

只使用当前用户指定的配置位置或经工具/官方文档确认的位置；本技能没有精确端点、配置字段和路径规范，不猜测写入。

执行配置前保留原配置，避免显示凭据。切换后分别验证模型列表、真实对话和所需能力；报告哪些通过、哪些仅来自历史记录。
