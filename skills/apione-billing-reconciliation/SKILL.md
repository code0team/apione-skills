# apione-billing-reconciliation

读 [计费与对账](references/billing.md)。先确定币种、单位、分组/项目、模型、实际请求参数和计费时间，再计算。

最新文字说明中分组特殊价覆盖标准价和倍率；旧版本曾要求特殊价再乘倍率，两者不能混用。核对当前部署并用一笔可审计用量验证。

输出定价来源、公式、参数、预期与实际金额、日志依据及状态。业务确认、研发声称修复和用户复测通过分开记。没有完整用量、费率或单位时不编造金额。

需要改账、退款或更新线上价格时按本次用户授权范围操作，查询本身不授权写入。
